# Qt XCB private compatibility headers

The versioned directories contain the private XCB headers required by
`dde-qt6platform-plugins` when a distribution does not ship them in
`qt6-base-private-dev`.

The `6.10.2` directory is copied without modification from
`src/plugins/platforms/xcb` at Qt `qtbase` tag `v6.10.2`, commit
`000d6c62f7880bb8d3054724e8da0b8ae244130e`:

https://github.com/qt/qtbase/tree/v6.10.2/src/plugins/platforms/xcb

Each header retains its upstream SPDX license declaration. Qt's licensing
terms are documented at:

https://www.qt.io/licensing
